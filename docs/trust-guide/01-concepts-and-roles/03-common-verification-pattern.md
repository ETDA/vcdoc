# 1.4 หลักการตรวจสอบ — ใครตรวจใคร

## 1.4 หลักการตรวจสอบ (Common Verification Pattern)

ในระบบนี้ ทุกฝ่ายตรวจสอบความน่าเชื่อถือด้วยวิธีเดียวกัน คือ **ดูรายชื่อที่เชื่อถือได้ (TrustList)** ที่ ETDA เป็นผู้ดูแล แต่ว่า "ตรวจใคร" นั้นต่างกันไปตามหน้าที่ของแต่ละฝ่าย

ตารางด้านล่างสรุปว่าใครต้องตรวจใครบ้าง ถ้าอยากรู้รายละเอียดเต็ม เช่น field หรือ error code ให้ตามลิงก์ในตารางไปอ่านที่บทที่เกี่ยวข้อง

### ใครตรวจใคร

| ผู้ตรวจ | ตรวจใคร | ดูรายละเอียดเต็มที่ |
|---------|---------|----------------------|
| Wallet | Issuer (ตอนรับบัตร) และ Verifier (ตอนถูกขอดูบัตร) | [3.2.5 การตรวจสอบ Trustlist](../03-issuance-flow/02-full-flow/06-verification-details.md), [4 Full Flow — จุดตรวจที่ 1](../04-presentation-flow/02-full-flow/02b-full-flow-technical-detail.md) |
| Issuer | Wallet Provider (ก่อนออกบัตร) | [3.2.5 การตรวจสอบ Trustlist](../03-issuance-flow/02-full-flow/06-verification-details.md) |
| Verifier | Wallet Provider ก่อน แล้วตามด้วย Issuer (ตอนรับบัตรที่แสดงมา) | [4 Full Flow — จุดตรวจที่ 2–4](../04-presentation-flow/02-full-flow/02b-full-flow-technical-detail.md) |

> หน้านี้เก็บแค่ภาพรวมว่า "ใครตรวจใคร" เพื่อไม่ให้เนื้อหาซ้ำกับบทอื่น ส่วนวิธีตรวจแบบละเอียดทีละขั้นอยู่ในบท 3 (การออกเอกสาร) และบท 4 (การแสดงเอกสาร)
